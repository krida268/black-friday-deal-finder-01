# Bargain Beacon — Real Black Friday Deal Finder

A static deal-finder site of 31 real Black Friday and Cyber Monday deals, each found and checked by an AI agent on Black Friday itself, 27 Nov 2026, at Amazon, Best Buy, Walmart and Target. Every deal carries its product, store, store link, sale price, usual price, discount, check time, source — and an honest verdict on whether it is really a deal (new low, strong deal, or routine).

- **Search** any product, brand or store
- **Filter** by category, store and minimum discount; **new-lows-only** toggle
- **Sort** by biggest discount, biggest dollar saving, price, or name
- **Deal pages** with the full evidence, check time, source and similar deals
- **Phone layout** that works on a small screen

Play it: open `app/index.html` in desktop Chrome (or `node serve.ts`, then http://localhost:8080). No build step, no network requests at run time — the deals are data in `app/deals.js`.
